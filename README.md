# Sluggers Characters Beta

A patcher for Mario Super Sluggers (Wii, USA, RMBE01) that adds new characters, recolors and features to your own copy of the game.

**Download:** see [Releases](../../releases). Unzip, run `Sluggers Characters Beta.exe`, and point it at your own clean game.

Nothing of Nintendo's is in this download: everything the patch copies from the game is read from your copy.

See `README.txt` for full instructions and `CREDITS.md` for everyone who made this possible.
